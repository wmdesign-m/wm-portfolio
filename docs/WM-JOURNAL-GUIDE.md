# Part 1 — Brand Foundation

## 01. Philosophy

この章では、WM Journalの最上位思想だけを扱います。媒体ごとの役割や導線は「02. Brand Position」「03. Media Strategy」を参照してください。

### Brand Statement

**心地よく働き、心地よく暮らす。**

WM Journalは、Web制作という仕事を通して得た経験や、日々の暮らしの中で見つけた「心地よさ」を綴るWebマガジンです。Web制作の技術を教えることだけを目的としたBlogではありません。

仕事を支える道具、働き方、暮らし、実際に使ったもの、自分自身の経験や価値観を通して、「WM Designらしさ」を伝えるブランドメディアとして運営します。

情報だけではなく、その背景にある考え方や選ぶ理由まで届けることで、読者との長期的な信頼関係を築くことを目指します。

### Mission

**実体験を通して、心地よく働き、心地よく暮らすためのヒントを届ける。**

インターネット上の情報をまとめることではなく、自分自身が経験したこと、実際に使ったもの、時間をかけて感じたことを記事にします。読者が「参考になった」だけではなく、「自分も試してみよう」と思えるような、実践的で誠実な情報発信を大切にします。

### Vision

WM Journalは、Web制作・暮らし・働き方を自然につなぐライフスタイルWebマガジンを目指します。仕事と暮らしを切り離して考えるのではなく、心地よい仕事環境、心地よい暮らし、心地よい働き方が互いに影響し合うという考えを軸に、長く読まれるメディアを育てていきます。

### Core Values

| Value            | Meaning                                                                                        |
| ---------------- | ---------------------------------------------------------------------------------------------- |
| Experience First | 自分で試したこと、使ったもの、感じたことを中心に発信し、憶測や未確認情報だけで記事を書かない。 |
| Honest           | 良い点だけではなく、気になった点や失敗も正直に伝える。                                         |
| Calm             | 感情をあおる表現や不安を煽るタイトルではなく、安心して読み進められる文章を大切にする。         |
| Quality          | 更新頻度よりも品質を優先し、公開後も必要に応じて内容を見直す。                                 |
| Long Life        | 一時的な流行よりも、数年後も価値のある記事を積み重ねる。                                       |

### Writing Promise

公開するすべての記事は、以下の基準を満たすことを目標とします。

- 実体験が含まれている
- 読者にとって役立つ内容である
- 過度な誇張や断定をしていない
- 読み終えたあとに、小さな気付きや行動のきっかけが残る
- WM Journalらしい穏やかなトーンで書かれている

詳細な文体ルールは「06. Writing Style」を参照してください。

### Guiding Principle

記事を書く中で迷ったときは、必ずこの言葉に立ち返ります。

> **心地よく働き、心地よく暮らすために、本当に役立つことだけを書く。**

## 02. Brand Position

この章では、WM Journalが市場・読者・WM Designブランド内でどのような立ち位置にあるかを扱います。媒体間の導線は「03. Media Strategy」を参照してください。

### Why WM Journal Exists

WM Journalは、Web制作の知識を発信するためだけのBlogではありません。WM Designというブランドの価値観や人柄、働き方、そして日々の暮らしを伝えるためのブランドメディアです。

Portfolioでは制作実績や専門性を伝えます。一方で、Portfolioだけでは伝えきれない仕事への向き合い方、道具を選ぶ基準、暮らしを整える考え方、実際に使ったものへの率直な感想、心地よく働くための工夫を、WM Journalで丁寧に発信します。

### Brand Concept

WM Journalが目指すのは、**「Web制作者が運営するライフスタイルWebマガジン」**です。

一般的なWeb制作Blogのように、HTMLの書き方、CSSの解説、WordPressの設定方法だけを発信する場所ではありません。また、暮らしだけを扱う一般的なライフスタイルBlogでもありません。

仕事と暮らしの両方を大切にすることで、**「心地よく働くことは、心地よく暮らすことにつながる」**というブランドの価値観を表現します。

### What Makes WM Journal Different

WM Journalが他のBlogと違う最大の特徴は、**実体験を中心に記事を書くこと**です。「検索されそうだから書く」のではなく、「実際に経験したことだから伝えたい」という姿勢を優先します。検索ボリュームだけを目的に記事を量産することはありません。

経験、感想、背景、選んだ理由まで含めて、一つの記事としてまとめます。

### Reader Experience

読者に届けたい体験は、情報を得ることだけではありません。記事を読み終えたあと、次のように感じてもらえることを目指します。

- 少し暮らしを整えたくなった
- 自分も試してみようと思えた
- この人の考え方が好きだと感じた
- また次の記事も読んでみたい
- WM Designというブランドに親しみを感じた

記事は「読む情報」ではなく、読者の毎日に小さな変化を与える存在を目指します。

### Target Audience

WM Journalの主な読者は、以下のような方を想定しています。

#### Primary Target

- 30〜50代を中心とした読者
- 女性を中心とした読者
- 在宅ワークやフリーランス、自分らしい働き方に関心がある方
- 暮らしを整えながら働きたい方
- デザインやインテリアが好きな方
- 良いものを長く使いたい方
- Web制作やオンラインショップ運営に興味がある方
- デスク環境や愛用品レビューを探している方

#### Secondary Target

- WordPressやSTUDIOを利用している方
- ShopifyやEC運営に関心がある方
- 制作環境を見直したい方
- 40代から学び続ける働き方に関心がある方

### Primary Reader Profile

WM Journalでは、年齢や性別だけで読者を固定せず、以下のような生活や価値観を持つ方を想定読者として考えます。

仕事は大切にしながらも、暮らしを犠牲にしたくない。自宅のデスクやインテリア、日々使う道具を少しずつ整え、自分に合う環境をつくりたいと考えている。流行やランキングだけで選ぶよりも、良いものを長く使いたい気持ちがある。

過度に広告的な記事よりも、実際に使った人の率直な意見を読みたい。短い結論だけではなく、選んだ背景や使い続けて感じたことまで丁寧に知りたい。そうした読者に向けて、WM Journalは静かで誠実な情報を届けます。

### Not for Everyone

WM Journalは、以下の目的には必ずしも適していません。

- 最安値だけを基準に選びたい人
- 結論やランキングだけをすぐ知りたい人
- 刺激的で強い表現を求める人
- 未使用商品を含む大量比較記事を求める人
- 技術マニュアルだけを探している人

これらのニーズを否定するのではなく、WM Journalでは別の価値を優先します。読者が自分に合うものを選ぶための背景、実感、考え方を丁寧に届けることを大切にします。

### Brand Personality

WM Journalが目指すブランドイメージは、上品、落ち着き、誠実、丁寧、温かみ、清潔感、女性らしさ、甘すぎなさ、ミニマル、信頼感です。派手な演出や強い言葉よりも、静かな世界観の中で読者との信頼を育てていきます。

### Position in the WM Design Brand

WM Design全体におけるWM Journalの役割は、**ブランドへの共感を育てること**です。

| Media      | Main Purpose                         |
| ---------- | ------------------------------------ |
| Portfolio  | 制作を依頼するための信頼をつくる     |
| Works      | 制作力・課題解決力を伝える           |
| About      | 制作姿勢・価値観を伝える             |
| WM Journal | 人柄・暮らし・働き方・実体験を伝える |
| Contact    | 安心して相談してもらう               |

WM Journalは営業ツールではありません。ブランドへの共感を育てることで、結果としてPortfolioやWorksにも興味を持ってもらうことを目指します。

### Long-Term Goal

WM Journalは、毎日更新することを目標にしません。長く価値のある記事を積み重ね、5年後、10年後も読み返されるWebマガジンを目指します。更新頻度よりも、「この記事を読めてよかった」と思ってもらえる品質を優先します。

## 03. Media Strategy

この章では、媒体間の役割と導線だけを扱います。ブランドの立ち位置は「02. Brand Position」、SNS投稿の具体ルールは「12. SNS Integration」を参照してください。

### Brand Ecosystem

| Media      | Purpose                                              |
| ---------- | ---------------------------------------------------- |
| Portfolio  | 制作力・専門性・実績を伝える                         |
| WM Journal | 人柄・価値観・暮らし・働き方を伝える                 |
| X          | 学び・制作過程・日々の気付きをリアルタイムで発信する |
| Instagram  | ブランドイメージ・世界観・写真・ビジュアルを伝える   |

それぞれの役割を重複させず、補完し合うことを基本とします。

### Role of WM Journal

WM Journalの役割は、**ブランドへの共感を育てること**です。Portfolioでは「依頼したい」と思ってもらうことが目的ですが、WM Journalでは「この人の考え方が好き」「この人が選ぶものなら信頼できそう」と感じてもらうことを目指します。

### Content Flow

```text
日常の経験
↓
Xでリアルタイム発信
↓
価値があるテーマを整理
↓
WM Journalで長文記事化
↓
Instagramで世界観をビジュアル化
↓
Portfolio・About・Worksへ自然につながる
```

同じ内容をそのまま転載することは行いません。

### Portfolioとの関係

Portfolioは「制作を依頼するための信頼」を伝える場所です。WM Journalでは、Portfolioでは伝えきれない暮らし、働き方、道具、考え方、実体験を伝えます。

### Xとの関係

Xでは、制作中の気付きや学習の記録、その日の発見など、リアルタイム性の高い情報を発信します。

### Instagramとの関係

Instagramでは、ブランドの世界観を伝えます。写真やデザインを通して、WM Designらしい空気感を発信します。

### Basic User Journey

```text
X
↓
WM Journal
↓
About
↓
Works
↓
Contact
```

```text
Instagram
↓
WM Journal
↓
Portfolio
↓
Works
↓
Contact
```

Blogから直接Contactへ強く誘導することは避けます。まずはブランドへの共感を育てることを優先します。

### Internal Linking Strategy

Workspace記事からReview記事へ、Review記事からLifestyle記事へ、Workstyle記事からAboutやWorksへなど、読者が自然に読み進められる導線を設計します。

### Long-form First

まずはWM Journalの記事を完成させ、その内容をXやInstagramへ最適化して展開します。短文を長文化するのではなく、長文を各媒体向けに再編集することを基本方針とします。

### Success Indicators

WM Journalでは、PVだけを成功指標にしません。重要視する指標は以下です。

- 最後まで読まれる記事
- 保存される記事
- SNSで自然にシェアされる記事
- リピーター数
- 再訪率
- 指名検索
- WM DesignやWM Journalでのブランド検索
- 記事から関連記事への回遊
- Portfolioへの流入
- About・Worksへの自然な遷移
- Aboutページの閲覧
- 記事の保存やブックマーク
- SNS経由だけでなく検索から継続的に読まれること
- ブランドへの共感

数字だけではなく、ブランド価値を積み重ねることを優先します。

# Part 2 — Editorial Direction

### Workspace

心地よく働くための環境づくり。

#### Purpose

仕事を支える環境や道具について扱います。デスク環境そのものだけでなく、集中しやすい空間づくりや、作業効率を高める工夫まで含めます。

#### Main Topics

- デスク環境
- 在宅ワーク環境
- PC周辺機器
- デスク整理
- 椅子
- モニター
- キーボード
- マウス
- 照明
- ケーブル収納
- 作業効率化
- Workspace紹介
- デスクレイアウト
- 集中しやすい環境づくり

#### Example Articles

- 心地よく働くためのデスク環境を整える
- デスクの上に置くもの、置かないもの
- 作業効率が上がった小さな工夫
- 長時間作業を快適にする環境づくり
- デスク周りで本当に買って良かったもの

#### Include

作業環境全体の整え方、デスクや収納の使い方、集中しやすさを高める工夫、仕事を支える道具の配置や選び方。

#### Do Not Include

商品単体レビュー、WordPress設定方法、STUDIO操作方法、学習方法、制作ノウハウ。それらはReviewまたはWorkstyleで扱います。

#### Related Tags

デスク環境、PC周辺機器、ガジェット、モニター、キーボード、マウス、チェア、照明、収納、文房具。

#### Category Selection Example

デスクライト単体を使った感想はReview、デスク環境全体の中で照明をどう整えたかはWorkspaceに分類します。

### Lifestyle

#### Theme

心地よく暮らし、心地よく働くための日常。

#### Purpose

暮らしそのものをテーマに記事を書きます。仕事だけではなく、仕事を支える生活全体を対象とします。

#### Main Topics

- 暮らし
- 習慣
- 朝時間
- 夜時間
- インテリア
- 収納
- リラックス
- 時間管理
- 家事
- ワークライフバランス
- 40代からの暮らし
- 心地よい生活

#### Example Articles

- 朝の30分で整える仕事の準備
- 夜にしている小さな習慣
- 部屋を整えると集中しやすくなった話
- 無理をしない働き方を考える

#### Include

暮らしを整える習慣、仕事と日常の切り替え、インテリアや収納の考え方、無理をしない時間の使い方。

#### Do Not Include

商品のレビューを主役にはしません。レビューが中心になる場合はReviewカテゴリへ分類します。

#### Related Tags

暮らし、習慣、インテリア、整理、休息、時間管理、家事、40代の働き方。

#### Category Selection Example

仕事と暮らしの切り替えについて書く記事はLifestyle、使用した家電の詳細な感想はReviewに分類します。

#### Include

愛用品、Webサービス、学習サービス、書籍、サブスクリプション、家電、ガジェット、PC周辺機器。

#### Main Topics

- フリーランス
- Web制作
- WordPress
- STUDIO

- 学び方
- 時間管理
- 制作環境
- クライアントワーク
- EC運営経験
- 働き方

#### Example Articles

- WordPressとSTUDIOをどう使い分けているか
- Shopify運営で学んだこと
- 一人で制作を続ける工夫
- 制作時間を確保する方法
- 40代から学び続けるために意識していること

#### Include

制作の中で得た気付き、働き方の選択、学び続けるための工夫、Web制作と暮らしのバランス。

#### Do Not Include

#### Related Tags

#### Category Selection Example

| Article Focus                            | Category  |
| ---------------------------------------- | --------- |
| デスクライトを紹介する記事               | Review    |
| デスク環境全体を紹介する記事             | Workspace |
| 仕事と暮らしの切り替えについて書く記事   | Lifestyle |
| STUDIOを仕事でどう使っているかを書く記事 | Workstyle |

## 05. Editorial Policy

この章では、編集判断のみを扱います。文体や語尾などの詳細は「06. Writing Style」、レビュー構成は「08. Review Template」、収益化ルールは「11. Affiliate Policy」を参照してください。

### Editorial Mission

記事を書く目的は、情報を増やすことではありません。読者の仕事や暮らしが、ほんの少しでも心地よくなるきっかけを届けることです。

### Editorial Principles

| Principle                     | Rule                                                                                                                   |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Experience Before Information | 検索すれば分かる内容だけでは記事にせず、自分自身が経験したこと、実際に試したこと、時間をかけて感じたことを中心にする。 |
| Honest Over Perfect           | 完璧に見せることより、正直であることを優先する。失敗や迷いも、読者の役に立つのであれば共有する。                       |
| Quality Before Quantity       | 更新頻度よりも記事の品質を優先し、公開後も必要に応じて記事を改善する。                                                 |
| Long-term Value               | 一時的な流行より、数年後も役立つ内容を優先する。                                                                       |
| Reader First                  | SEOは重要だが、検索順位のために読みにくい文章を書くことはしない。                                                      |

### Editorial Standards

- 実体験が含まれている
- 一次情報がある
- 読者に役立つ内容である
- 根拠がある
- 誇張していない
- 読みやすい構成になっている
- ブランドトーンに合っている
- 将来読み返しても価値がある

### Topics We Write About

心地よい仕事環境、暮らし、働き方、愛用品、実際に使ったサービス、Web制作者としての日常、作業環境、習慣、レビュー、時間の使い方。これらは、ブランドコンセプト**「心地よく働き、心地よく暮らす。」**につながる内容であることを基本とします。

### Topics We Avoid

- 技術解説だけの記事
- 検索ボリュームだけを狙った記事
- 未使用商品や未使用サービスのレビュー
- 口コミだけで書いた記事
- 公式サイトの内容をまとめただけの記事
- 読者の不安や期待を必要以上に煽る記事
- WM Designのブランドと関係が薄い記事

### Experience Before Information

情報よりも経験を優先します。検索すれば分かる内容だけでは記事にしません。

### Honest Over Perfect

完璧に見せることより、正直であることを優先します。

### Calm Communication

読者の不安を煽る表現や、急かすような編集判断は避けます。詳細な語尾や表現ルールは「06. Writing Style」を参照してください。

### Quality Before Quantity

無理に毎日更新を目指さず、公開後も必要に応じて記事を改善します。

### Long-term Value

記事は資産として積み重ね、数年後に読み返しても意味のある内容を優先します。

### Reader First

記事を書くときは、Googleよりも読者を優先します。

## 06. Writing Style

この章では、文章をどのように書くかを扱います。

### Tone of Voice

WM Journalの基本文体は、丁寧な「です・ます」調です。雑誌編集者のように整っていて、信頼できる知人のように親しみがある文章を目指します。専門家として上から教えず、感情を大げさにせず、読者へ結論を押し付けず、体験と事実を区別して書きます。

### 一人称

一人称は原則として「私」を使用します。

### 読者への呼びかけ

読者を強く「あなた」と呼びすぎないようにします。「こういう方には」「同じように感じる方には」のように穏やかな表現を使います。

### 敬体・常体のルール

本文は「です・ます」調で統一します。タイトルや箇条書きでは必要に応じて体言止めを使用できます。

### 語尾

同じ語尾が続きすぎないように整えます。「です」「ます」「思います」「感じました」を自然に使い分けます。

### 一文の長さ

一文は長くしすぎず、読点が多くなる場合は文を分けます。

### 段落の長さ

段落は2〜4文程度を目安にします。1文ごとの不自然な改行は避けます。

### 漢字とひらがなのバランス

「出来る」は「できる」、「下さい」は「ください」を基本にします。

### 専門用語の扱い

専門用語は必要な場合に使い、初めて出す言葉は文脈で理解できるように補足します。

### 数字・英字・記号の表記

数字は原則として半角を使用します。英字サービス名は正式表記を優先し、Title Caseを基本にします。

### 見出しの書き方

煽りや断定を避け、内容が自然に想像できる言葉にします。

### 導入文の書き方

記事の背景、なぜ書くのか、どんな読者に役立つのかを短く示します。

### まとめ文の書き方

強い購入誘導や断定を避け、読者が自分の環境に置き換えて考えられるように整理します。

### 推奨表現

- 私の場合は
- 実際に使ってみると
- 現在の環境では
- 個人的には
- こういう方には合いやすいと思います
- 使い方によっては気になるかもしれません

### 避ける表現

- 絶対
- 必ず
- 誰にでも
- これ一択
- 人生が変わる
- 知らないと損
- 今すぐ買うべき
- 完全保存版
- 最強
- 神アイテム

### AIらしい不自然な文章を避けるルール

一般論だけで段落を埋めない、実体験がない断定をしない、同じ構文を連続させない、読者の感情を勝手に決めつけない、体験・事実・推測を分けて書くことを徹底します。

# Part 3 — Article Planning

## 07. Article Structure

通常記事は、Title、Lead、Background、Main Content、Personal Experience、Practical Tips、Summary、Related Articlesの流れを基本にします。導入文では背景と読みどころを示し、本文では事実、体験、感想を分けて整理します。まとめでは強い購入誘導や断定を避け、読者が自分の環境に合わせて判断できる余白を残します。

## 08. Review Template

レビュー記事は、必ず自分自身が使用した商品やサービスに限定します。未使用商品、口コミだけ、公式サイトの要約だけ、AIだけで生成したレビューは公開しません。

### Required Elements

- Product / Service Information
- Why I Chose It
- Usage Period
- Usage Environment
- What I Liked
- What Concerned Me
- Who It May Suit
- Who It May Not Suit
- Final Impression
- Disclosure

### Relationship with Affiliate Policy

Review記事は収益化の中心になり得ますが、収益化のためにレビュー基準を緩めません。詳細は「11. Affiliate Policy」を参照してください。

## 09. SEO & Search Intent

SEOは重要ですが、検索順位のためにWM Journalらしさを損ないません。検索意図を確認しながらも、実体験、背景、選んだ理由を中心に構成します。キーワードは自然に使用し、不自然な繰り返しや見出しへの詰め込みは避けます。

# Part 4 — Visual & Monetization

## 10. Image & Illustration Guidelines

画像は、記事の理解とWM Journalらしい世界観を支えるために使用します。装飾だけを目的に増やさず、実際の製品、環境、状態、手順、雰囲気が伝わるものを優先します。Blogトップデザインそのものの説明はここでは扱いません。

### Photography

WorkspaceやReviewでは、実際に使用している環境が伝わる写真を優先します。暗すぎる写真、過度にぼかした写真、商品や状態が確認しにくい写真は避けます。

### Illustration

イラストは、WM Designらしい柔らかさや世界観を補う目的で使用します。記事内容を曖昧にするためではなく、読者の理解や余韻を助けるために使います。

### Accessibility

画像には内容が伝わる代替テキストを設定します。

## 11. Affiliate Policy

WM Journalでは、ReviewとWorkspaceを収益化の中心にします。ただし、収益化は記事の目的ではなく、実体験に基づく記事の中で自然に発生するものとします。

### Rules

- 未使用商品を広告目的で紹介しない
- アフィリエイトリンク、提供品、PR、広告案件がある場合は分かりやすく明記する
- 良かった点だけでなく、気になった点や合わない可能性も書く
- 特定商品の過度な推奨をしない
- 広告主が決まっている前提で書かない
- 具体的なアフィリエイトサービス名を断定しない
- 医療・健康効果を断定しない
- 架空の成果数値を書かない

LifestyleとWorkstyleでは、収益化よりもブランド理解と信頼形成を優先します。

## 12. SNS Integration

SNSは、WM Journalの記事をそのまま短くする場所ではありません。XとInstagramそれぞれの役割に合わせて、記事の要点、制作中の気付き、世界観を再編集して届けます。

### X

Xでは、制作中の気付きや学びを発信します。制作メモ、STUDIOで気付いたこと、WordPressで困ったこと、デザインの学び、Codingの改善、コミュニティで得た学び、Blog記事化前の小さな気付きを扱います。

### Instagram

Instagramでは、世界観とビジュアルを発信します。デスク写真、愛用品、暮らし、Workspace、ラインアート、ファッションイラスト、Blog更新のお知らせ、制作実績の一部紹介などを扱います。

### Blog to SNS

WM Journalの記事を公開したら、Xでは学びや気付き、Instagramでは写真やデザインとして再編集します。同じ文章をそのまま転載するのではなく、媒体ごとに読みやすい形へ変換します。

サービス名や分野名では「Web」を使用します。一般的な読み物の中で柔らかく表現したい場合のみ「ウェブ」を使用できますが、表記ゆれを避けるため基本は「Web」に統一します。

### SNS

XやInstagramなどをまとめて指す場合に使用します。具体的な媒体名が必要な場合は、SNSとまとめず「X」「Instagram」と書き分けます。

### X

リアルタイムな気付き、制作メモ、学びの発信場所として扱います。旧名称は原則として使用しません。

### Instagram

世界観、写真、ビジュアルを発信する媒体として扱います。略称は必要な場合に限定します。

### EC

運営や仕組みを説明する文脈で使用します。読者に伝わりやすい場面では「オンラインショップ」と書き換えます。

### オンラインショップ

読者向けに分かりやすく伝えたい場合に使用します。Shopifyなど具体的なサービス名と併用する場合は、文脈に合わせて使い分けます。

### Webサイト

制作物や一般的なサイトを指す場合は「Webサイト」を使用します。

### ホームページ

一般読者に馴染みのある表現として必要な場合のみ使用します。制作・設計の文脈では「Webサイト」を基本にします。

### Service Names

英文サービス語は原則としてTitle Caseを使用します。ブランド名や正式サービス名は公式表記を優先します。
