Expertise

01

Coding

HTML / CSS Coding

デザインの意図を丁寧に読み取り、細かなレイアウトや余白まで大切にしながら実装します。スマートフォンへの対応はもちろん、表示速度や更新・修正のしやすさにも配慮し、長く使いやすいWebサイトを目指します。

対応内容

  • JavaScript
  • レスポンシブ対応
  • デザインカンプからの実装
  • 保守しやすいCSS設計
  • アクセシビリティへの配慮
  • 表示速度・画像最適化
  • 軽量なアニメーション
02

WordPress

WordPressサイト構築

公開後もご自身で無理なく更新を続けられるよう、運用のしやすさまで考えてWordPressサイトを構築します。デザインを形にするだけでなく、お知らせやBlog、Worksなど、必要な情報を更新しやすい仕組みづくりにも対応します。

対応内容

  • オリジナルデザインのWordPress化
  • テーマカスタマイズ
  • Gutenberg（ブロックエディター）
  • カスタム投稿タイプ
  • 再利用できるブロック・パターン
  • Blog・Worksなどの更新機能
  • レスポンシブ対応
  • 基本SEO設定

    結婚・出産を機に退職

    結婚と出産を機に退職し、子育てを中心とした生活へ移りました。

    運営上の課題をきっかけに、Web制作の学習を開始

    テーマを活用した構築やカスタマイズを学び、更新しやすく、長く使えるサイト設計への理解を深めています。

    フリーランス「WM Design」として活動開始

    Coding・WordPress・Designを軸に、STUDIOサイト制作にも対応しながら、デザインから実装まで一貫したWeb制作を行っています。
