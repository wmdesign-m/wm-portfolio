# WM Design Brand Guide

## 1. このドキュメントの目的

このドキュメントは、WM Designのブランド全体を定義する最上位ガイドです。

対象範囲：

- ポートフォリオサイト
- WordPressサイト
- SNS
- Blog
- 制作実績紹介
- 営業資料・提案書・名刺
- AIへの指示
- 今後のブランド展開

デザイン、文章、実装、発信内容がばらばらにならないよう、すべての制作物はこのガイドを基準に判断します。

実装やコーディングの詳細ルールは、別ファイルの `SKILL.md` を参照してください。

### 情報の優先順位

資料間で内容が異なる場合は、以下の順番で判断します。

1. ユーザーからの最新の明示的な指示
2. この `WM-DESIGN-GUIDE.md`
3. `SKILL.md`
4. 現在のポートフォリオ実装
5. 旧版のBrand Guidelines、UI Design System、Master Guide

旧資料にあるBlocksy固定、Stackable固定、JavaScriptを必要最小限に限定する方針は、現在の正式方針ではありません。

## 2. Brand Name and Logo System

ブランド名は **WM Design** です。

### 基本表記

文章、プロフィール、サービス説明、SNS本文などでは、原則として `WM Design` を使用します。

ロゴデータとして制作された大文字表記は、正式なロゴ表現として `WM Design` のまま使用して構いません。

### 正式ロゴの方向性

正式ロゴは、既に採用しているWMのモノグラムとブランド名を使用します。

特徴：

- Wの流れを活かした、しなやかで印象的なライン
- Mは細く、軽やかで繊細
- 海外Webスタジオやファッション誌を感じるエディトリアルな印象
- 女性らしさはあるが、甘くしすぎない
- Web DesignとCodingの双方を扱うブランドとして、装飾より構造美を重視
- 白、ライトベージュ、ブラウン、グリーンの世界観に調和する

### ロゴバリエーション

最低限、以下を正式データとして管理します。

- Primary Logo：通常背景用
- Brown Logo：白・ライトベージュ背景用
- White Logo：濃色・写真背景用
- Monogram：WMのみ。Favicon、SNSアイコン、小さな表示用

推奨ファイル名：

```text
wm-design-logo-primary.svg
wm-design-logo-brown.svg
wm-design-logo-white.svg
wm-design-monogram.svg
```

SVGを基本とし、必要に応じてWebPまたはPNGを書き出します。

### ロゴカラー

ロゴの基本色は、本文色と調和するダークブラウンまたはチャコールを使用します。

- 推奨ダーク：`#2F2F2F`
- 白抜き：`#FFFFFF`
- ブランドグリーン版：`#7C8F73`（用途を限定して使用）

ロゴをHoverカラー `#A7B59A` に常時設定しません。

### ロゴ余白

ロゴの周囲には、モノグラムの線幅や文字高に対して十分な余白を確保します。

- 周囲に最低でもロゴ文字高の約25%を確保
- 他の文字、罫線、画像へ近づけすぎない
- ヘッダーでは視認性を保ちつつ、ナビゲーションより過度に主張させない

### 最小サイズ

- 横組みロゴ：Web上では幅120px以上を目安
- モノグラム：24px以上を目安
- 小さい表示では細い線がつぶれないか実機確認する

### 禁止事項

- 縦横比を変える
- ロゴを回転・変形する
- 影、縁取り、グラデーションを無断で加える
- ブランドカラー以外へ変更する
- 背景とのコントラストが不足した状態で使用する
- ロゴの一部だけを別フォントで再現する
- 正式ロゴをテキスト入力だけで代用する

画像の代替テキストは、原則として `WM Design` とします。装飾として重複する場合は、文脈に応じて空の代替テキストを使用します。

## 3. Brand Concept

### Primary Brand Message

### Design & Build with Care.

**丁寧につくり、丁寧に育てる。**

旧ガイドで使用していた `Design with Purpose.` は廃止せず、デザイン思想を説明する補助的なPrincipleとして使用できます。ブランドのメインメッセージは `Design & Build with Care.` に統一します。

WM Designは、見た目を整えるだけではなく、目的、情報、使いやすさ、更新のしやすさまで丁寧に設計するWeb制作ブランドです。

一時的に目立つ表現よりも、事業やサービスの魅力が正しく伝わり、長く安心して使えるWebサイトを目指します。

## 4. Brand Mission

事業やサービスの想いを整理し、伝わる形に整え、長く育てていけるWebサイトをつくること。

デザインからコーディング、WordPress化まで一貫して対応し、依頼者が安心して相談できる制作パートナーを目指します。

## 5. Brand Positioning

WM Designの強みは、以下の順番で伝えます。

1. Coding
2. WordPress
3. Design

### Coding

デザインを丁寧に再現し、レスポンシブ対応、保守性、表示速度、アクセシビリティまで考えた実装を行います。

### WordPress

テーマを活用した構築、既存テーマのカスタマイズ、オリジナルデザインのWordPress化など、更新しやすく運用しやすいサイトを構築します。

特定テーマだけに依存する制作者として見せません。

### Design

事業の目的、ターゲット、情報の優先順位を整理し、伝わりやすく一貫性のあるWebデザインを制作します。

## 9. Brand Voice

文章は、プロのWeb制作者として客観的かつ建設的に書きます。

### 基本トーン

- 丁寧
- 誠実
- 分かりやすい
- 押し売りをしない
- 専門用語を使いすぎない
- 必要以上に自分を大きく見せない
- ネガティブな内容は、学びや改善につながる表現へ整える

### 避ける表現

- 根拠のない「高品質」「プロフェッショナル」
- 「必ず成果が出る」などの断定
- 過度に感情的な煽り
- 自信のなさを強く見せる表現
- 「何でもできます」という曖昧な表現

### 英語表記

英語のサービス名や見出しはTitle Caseを基本とします。

例：Design、Coding、WordPress、Works、About、Blog、Contact

技術的理由やロゴ表現を除き、不要なALL CAPSは避けます。

## 10. Visual Direction

### 全体印象

- 上品
- ミニマル
- 余白を活かす
- 白から淡いベージュを基調
- グレーを少し含んだ落ち着いた色
- グリーンをアクセントに使用
- 静かなエディトリアルデザイン
- 女性らしさは感じるが、甘すぎない

### 正式カラーパレット

過去のBrand GuidelinesとUI Design Systemで定義した以下の色を、WM Designの正式パレットとします。

| Token            |       Hex | 用途                                |
| ---------------- | --------: | ----------------------------------- |
| Primary Green    | `#7C8F73` | 主ボタン、リンク、アクセント、Focus |
| Hover Green      | `#A7B59A` | PrimaryのHover、淡い強調            |
| Background Beige | `#F8F5F0` | ページ背景、淡いセクション背景      |
| Surface White    | `#FFFFFF` | カード、フォーム、コンテンツ背景    |
| Text Primary     | `#2F2F2F` | 見出し、本文、ロゴの基本色          |
| Text Secondary   | `#6B6B6B` | 補助文、キャプション、メタ情報      |
| Border           | `#D8D4CC` | 罫線、入力欄、カード境界            |

カラーコードの前には必ず`#`を付けます。

### カラー使用比率の目安

- Background Beige / White：70〜80%
- Text Primary / Secondary：15〜20%
- Primary Green / Hover Green：5〜10%

グリーンを全面に使いすぎず、余白と淡色を主役にします。

### CSS Tokens

```css
:root {
  --color-primary: #7c8f73;
  --color-primary-hover: #a7b59a;
  --color-bg: #f8f5f0;
  --color-surface: #ffffff;
  --color-text: #2f2f2f;
  --color-text-secondary: #6b6b6b;
  --color-border: #d8d4cc;
}
```

既存サイトで同じ役割のCSS変数がある場合は、命名を無理に変更せず、値と用途を統一します。

### カラー運用ルール

- 主ボタンは`#7C8F73`、Hoverは`#A7B59A`
- ボタン文字は原則`#FFFFFF`
- 本文の基本色は`#2F2F2F`
- 補助文は`#6B6B6B`
- ページ背景は`#F8F5F0`を基本に、カードは`#FFFFFF`
- 罫線は`#D8D4CC`
- ページ単位で新しい近似色を増やさない
- 色だけで状態や意味を伝えない
- 写真上の文字は必ずコントラストを確認する

### タイポグラフィ

正式な基本フォントは以下です。

#### Heading / Display

- `Philosopher`
- 使用箇所：Hero、H1、H2、H3、H4、Pull Quote
- ブランドの上品さ、エディトリアル感、海外スタジオ感を表現する
- 英字だけでなく、日本語見出しと組み合わせる際は可読性を実機確認する

#### Body / UI

- `Noto Sans JP`
- 使用箇所：本文、ボタン、ナビゲーション、フッター、フォーム、キャプション
- 長文の可読性と日本語表示の安定性を優先する

#### Fallback

```css
:root {
  --font-heading: "Philosopher", "Times New Roman", serif;
  --font-body:
    "Noto Sans JP", "Hiragino Kaku Gothic ProN", "Yu Gothic", "Meiryo",
    sans-serif;
}
```

フォントの数を増やしすぎず、原則としてHeadingとBodyの2系統で運用します。

### タイポグラフィ基本値

- Base：Weight 400 / Line Height 1.8 / Letter Spacing 0.02em
- H1：Weight 700 / Line Height 1.2 / Letter Spacing -0.02em
- H2：Weight 700 / Line Height 1.3 / Letter Spacing -0.01em
- H3：Weight 700 / Line Height 1.4 / Letter Spacing 0
- H4：Weight 600 / Line Height 1.5 / Letter Spacing 0

具体的なfont-sizeは、既存のFluid Typographyとレスポンシブ設計を優先し、`clamp()`による調整を推奨します。

### 写真

- 明るく自然な光
- 白、ベージュ、グリーンと調和する色
- 清潔感と信頼感を優先
- 余白があり、文字を重ねても窮屈にならない構図
- プロフィール写真は、白を基調に観葉植物や柔らかな影が入る明るい印象

## 11. UI Direction

### ボタン

- 十分なタップ領域を確保する
- 過度に丸くしすぎない
- 主ボタンと副ボタンの違いを明確にする
- Hoverは軽く、自然な変化にする
- 文字、矢印、背景の動きが過剰にならないようにする

### カード

- 固定高さを避ける
- 内容量に応じて自然に伸びる設計
- 角丸、罫線、影は控えめに使用
- 同じ役割のカードは共通コンポーネント化する

### 余白

- セクション間の余白を十分に取る
- 見出し、本文、カード間のリズムを統一する
- 空白を情報整理の要素として扱う

## 12. Motion Direction

WM Designは、CSSやJavaScriptを活用した動きのあるサイトを目指します。

### Motionの目的

- 視線を自然に誘導する
- 情報の切り替わりを分かりやすくする
- ブランドの心地よさを表現する
- 操作に対する反応を伝える
- サイトの完成度を高める

### 使用してよい技術

- CSS Transition
- CSS Animation
- JavaScript
- Intersection Observer
- GSAP
- SVG Animation
- Canvas
- 必要に応じたスクロール連動表現

CSSで十分に実現できる場合はCSSを優先します。ただしCSSだけに限定せず、UXとブランド表現に必要であればJavaScriptやGSAPも活用します。

### 避ける表現

- 意味のない常時ループ
- 読むことを妨げる動き
- 操作を待たせる演出
- 過度なパララックス
- 大量の重いライブラリ
- 低スペック端末で極端にフレームレートが低下する演出
- `prefers-reduced-motion`を無視した実装

動きは「目立たせるため」ではなく、「心地よく伝えるため」に使用します。

## 13. WordPress Direction

WM Designは特定テーマ専用の制作者として見せません。

対応方針：

- SWELLなどのテーマを活用した構築
- 既存テーマのカスタマイズ
- オリジナルデザインのWordPress化
- Gutenbergを活用した更新しやすい構築
- 必要に応じたカスタム投稿タイプ
- 必要に応じたカスタムフィールド
- 再利用可能なブロックやパターン
- クライアントが更新しやすい管理画面設計

BlocksyやGutenbergは技術要素として利用しても構いませんが、ブランドの強みを特定テーマ名に限定しません。

WordPress化を前提に、静的HTMLの段階からコンポーネント分割と更新単位を意識します。

## 19. Accessibility and Performance

美しさと同じくらい、使いやすさと表示速度を重視します。

- セマンティックHTML
- キーボード操作
- 適切な代替テキスト
- 十分なコントラスト
- フォーカス表示
- `prefers-reduced-motion`
- 画像最適化
- 不要なJavaScriptを読み込まない
- レイアウトシフトを抑える
- モバイルでの操作性を優先する

アクセシビリティやパフォーマンスを理由に、動きをすべて排除する必要はありません。軽量で意味のある実装に調整します。

## 20. AI Direction

AIは、WM Designに関する提案を行う際、以下の2つの視点を必ず持ちます。

1. デザイン面：ブランディング、見た目、情報設計、UX上のメリット
2. 実装面：WordPress化、再利用性、保守性、レスポンシブ、表示速度、アクセシビリティ上の注意点

提案はデザインだけ、コードだけに偏らせません。

未確認の実績、対応経験、資格、数値は作りません。現在対応していることと、今後目指していることを区別します。

## 21. Decision Priority

判断に迷った場合は、以下の順で優先します。

1. ブランドの信頼感
2. ユーザーにとっての分かりやすさ
3. 事業目的
4. アクセシビリティ
5. 表示速度
6. WordPressでの更新性
7. 実装の保守性
8. デザインの新しさ
9. 装飾性

新しい表現であることよりも、目的に合い、長く使えることを優先します。

## 22. Guide Maintenance

このガイドは固定された完成物ではありません。ブランド、サービス、技術、実績の変化に合わせて更新します。

更新時の確認項目：

- 現在のサービス内容と一致しているか
- 未経験の内容を対応済みとして書いていないか
- サイト、SNS、Blogで表現が統一されているか
- 実装ルールと矛盾していないか
- WM Designらしい信頼感と心地よさを保てているか
