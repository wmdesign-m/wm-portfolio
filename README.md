# WM Design Portfolio

## Overview

WM Design のポートフォリオサイトです。

本サイトは、Webデザイン・コーディング・WordPress構築を一貫して行う
フリーランスWeb制作者「WM Design」のブランドサイトとして制作しています。

単なる作品集ではなく、

「この人なら安心して任せられる」

と思っていただけることを目的としています。

---

# Brand Concept

**Design & Build with Care.**

丁寧につくり、
丁寧に育てる。

デザインの美しさだけではなく、

・使いやすさ
・更新のしやすさ
・表示速度
・保守性

まで考えたWeb制作を大切にしています。
